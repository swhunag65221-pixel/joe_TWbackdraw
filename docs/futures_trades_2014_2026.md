# 台指期逐筆交易明細　2014–2026

策略：快速修復回檔入場（`tuned` 參數組）　標的：台指期 TX（已還原換倉價差的連續合約）
成交時點：訊號日**當天期貨收盤**（加權指數 13:30 收、台指期 13:45 收，中間 15 分鐘足夠下單）
槓桿：`風險預算 8% ÷ 停損距離`，上限 5 倍，**進場後不再調整口數直到出場**
停損線：`min(警戒線, 主防線 × 0.995)` —— 預設參數下警戒線與主防線重合，
所以真正的觸發點是主防線再往下 0.5% 的假跌破緩衝
資料截至 2026-08-19。

重現指令：

```bash
python3 scripts/futures_trades.py --since 2014-01-01      # repo 內
python tx_futures_backtest.py --trades-since 2014-01-01   # 單檔版
```

**欄位定義**

- **距離停損**：訊號日收盤到**停損線**的距離，槓桿就是由它算出來的。
  停損線 = `min(警戒線, 主防線 × 0.995)`；預設參數下兩條線重合，
  所以實際觸發點在主防線下方 0.5%（假跌破緩衝）。
- **槓桿**：`8% ÷ 距離停損`，上限 5 倍。進場後口數固定，實際槓桿會隨權益自然漂移。
- **期貨報酬**：期貨連續序列本身的漲跌（已還原換倉價差）。
- **權益報酬**：帳戶報酬，`1 + L ×（期貨報酬）` 再扣進出場各一次成本。
- **最大報酬（MFE）／最大不利（MAE）**：持有期間權益相對**進場點**的最高、最低。
- **期間最大回撤**：持有期間權益自**波段高點**起算的最大跌幅 —— 帳戶實際感受到的痛。

**欄位定義**

- **修復**：從谷底起算，幾個交易日把跌幅補回幾成。訊號門檻是 30 個交易日內補回 ≥60%。
- **警戒線**：`T + 50% ×（P − T）`，跌幅的 50% 回補位。
- **停損線**：`min(警戒線, 主防線 × 0.995)` —— 真正會成交的價位。預設參數下警戒線
  與主防線重合，主防線帶 0.5% 的假跌破緩衝，所以觸發點比警戒線再低 0.5%。
  2014 那筆連續三天收在主防線 9,041 之下（9,032 / 9,013 / 9,027）都被容忍，
  直到 12/15 收 8,985.63 跌破 8,996 才出場。
- **失效線**：谷底 T 本身，跌破代表整個劇本作廢，無條件全出且最優先檢查
  （實際上 8 筆都沒走到這裡）。

## 觀察

**停損太近不等於風險小 —— 反而是最危險的一筆。** 第 1 筆停損距離只有 1.85%，是 8 筆裡最近的，
槓桿因此推到 4.33x。結果指數只跌 1.5%，權益就虧 6.6%，期間一度浮虧 −8.0%，
遠超過「停損 1.85%」的假設。原因是訊號在收盤才判定，跳空與 15 分鐘時差都在放大實際滑價。
這是槓桿公式的結構性弱點：分母越小，任何超過假設的滑價就被放得越大。
第 2 筆同理（停損 2.28%、槓桿 3.51x、指數跌 1.7% → 權益虧 6.0%）。

**四筆虧損全部是「警戒清倉」，沒有一筆跌破失效線。** 停損機制本身運作正常，
虧的四筆平均只賠 4.4%，最深 −6.6%；賺的四筆是 +78.6% / +124.3% / +100.0% / +40.4%。
這是典型的**低勝率、高賠率**結構 —— 勝率 50% 但期望值極高，靠的是「賠小賺大」而不是「猜得準」。

**「最大報酬」與「權益報酬」的差距就是移動停利的成本。** 第 7 筆浮盈一度 +75.0%，
最後結在 +40.4%；第 5 筆 +154.1% → +124.3%。8% 的回撤停利在 2~3 倍槓桿下等於吐回
16~35 個百分點，這是換來「不猜頭部」的固定代價。

**期間最大回撤遠大於最大不利的那幾筆，才是心理上最難熬的。** 第 4 筆最大不利只有 −1.6%
（幾乎沒被套過），但期間最大回撤 −19.1%，因為它先賺到 +21.6% 再全數吐回；
第 2 筆（+17.0% → −6.0%，回撤 −19.6%）與第 7 筆（−19.8%）同理。
從沒真正虧大錢，卻要眼睜睜看獲利歸零。

**兩筆賺最多的都是深回檔（−28.7%、−26.7%），兩筆賠錢的都是淺回檔（−11.0%、−13.5%）。**
淺回檔的谷底離前高近，警戒線也近，槓桿被推高、容錯空間被壓縮，
是這個策略最不擅長的場景。若要改進，最直接的方向是對「回檔幅度 < 12%」的訊號
另外設槓桿上限，而不是讓公式一路推到 5x —— 但這是還沒驗證的想法，不是既有結論。
