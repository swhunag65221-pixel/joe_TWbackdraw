# 策略助理 A・第二輪：跨市場分散

程式：`lab/A2_diversify.py`、`lab/A2b.py`（穩健性附錄）
輸出：`out_a2.txt`、`out_a2b.txt`
視窗：**2016-01-04 ~ 2026-08-18（2,493 個交易日，10.6 年）** —— 三腿重疊期，
上界由美股 CSV 的結束日（2026-08-18）決定。
**未修改 repo 任何檔案。**

## 0. 結論先講（五句）

1. **分散對 Calmar 沒有幫助 —— 因為新版 TX 腿自己就把 Calmar 拉太高了。**
   TX 新腿在此視窗 Calmar **1.71**（加 step-down 是 **2.01**），任何含美股的固定權重
   組合都只到 **1.19～1.53**。舊研究 `allocation.md` 的結論（分散提高 Calmar）
   在舊 TX 腿（Calmar 1.04）上是對的，換成新腿之後**反轉**。
2. **但分散在「不依賴單一交易」這件事上是壓倒性的勝利，而且這不是視窗效應。**
   剔除 TX 腿最好的兩筆交易：TX 單腿 Calmar 1.71 → **0.95**（−0.75）、CAGR 36.6% → 17.8%；
   同樣剔除三腿各自最好的一筆，TX 50/25/25 組合只從 1.51 → **1.29**（−0.21）。
3. **實務可執行的「訊號再平衡」幾乎不用付代價。** SIG Calmar 1.51 vs 每日再平衡 1.50 ——
   `allocation.md` 說「每日再平衡是上界、實務做不到」是對的，但**這個上界幾乎沒有溢價**。
4. **前後段檢驗：分散唯一在兩段都一致改善的是「年化波動」**（TX50/25/25 另加 Sharpe）。
   Calmar、MDD、最差月份、最長水下**全部方向不一致**（前段分散贏、後段 TX 單腿贏）。
   按本專案標準，「分散能提高 Calmar」**未通過**。
5. **目標檢核：CAGR > 30% 達成（TX 50/25/25 SIG = 30.6%），Calmar > 4 差得很遠（1.51，差 2.49）。**
   而且這個 CAGR 是視窗給的：TX 腿在此視窗的 CAGR 是全期的 **1.76 倍**、Calmar 是 **2.71 倍**。
   折算回全期口徑，組合的 CAGR 大約是 **17～18%**、Calmar 大約 **0.55～0.60**。

### 1.3 「訊號再平衡」的定義（`allocation.md` §四.4 的實作）

- **鎖定**＝該腿的**策略部位**在場（固定口數，中途不能砍）。
  TX 的核心 0.5x 依 §19 是**每日再平衡的疊加**，資金隨時可調度，**不算鎖定**。
- **事件**＝任一腿由鎖定轉為未鎖定（策略部位出場回到現金）的當日。
- **SIG（主口徑）**：事件當日，把「未鎖定各腿的資金」按目標權重的比例重新分配給
  未鎖定的腿。鎖定中的腿完全不碰（不砍也不加）。
- **SIG-cap（對照）**：目標改用**當下總資產** × wᵢ 封頂，超出的部分變成閒置現金
  （報酬 0），等下一次事件再投入 —— 這是「不砍跑中部位」在總資產口徑下的直接代價。

### 4.4 讀法

- **「每日再平衡是上界」這個警語可以收回一大半。** 三種再平衡的 Calmar
  幾乎相同（50/25/25：每日 1.50、SIG 1.51、SIG-cap 1.51），CAGR 差 ±1pp，
  MDD 差 ±0.6pp。**「不砍跑中部位」這條實務限制在這個資產組合上幾乎不花錢**，
  因為三腿的訊號密度夠低、事件夠多（TX 出場 + 美股出場），權重不會漂移太久。
- **但沒有任何組合的 Calmar 打得過 TX 單腿（1.71）。** 最好的固定權重組合
  TX 50/25/25 只到 1.51；愈往美股加碼愈差（等權 1.20、US 50/50 0.71）。
  組合買到的是 **Sharpe（1.51 → 1.66~1.72）、年化波動（24.0% → 17.1%）
  與最差月份（−18.7% → −13.1%）**，不是 Calmar。
- 權重序列 TX 100 → 50/25/25 → 40/30/30 → 等權 → US 50/50 的 Calmar 是
  **單調遞減**（1.71 → 1.51 → 1.31 → 1.20 → 0.71）。這意味著「最佳權重」
  就在網格邊界上（TX 100%）—— **這正是 `allocation.md` §二警告的過擬合陷阱，
  所以我不把它當結論，只當警訊：目前的證據無法支持任何特定的分散比例。**

| **等權 1/3 組合** | 最多 −0.12（−10%） | 三腿最佳全剔，Calmar **−0.11（−9%）** |

**TX 單腿的 Calmar 1.71 有 44% 綁在兩筆交易上；組合的 Calmar 只有 9~14% 綁在
三筆交易上。** 這不是視窗效應 —— 它衡量的是「如果那一兩筆沒發生會怎樣」，
而 21 筆／27 年的樣本裡，這正是最該擔心的失效模式（助理 A 第一輪報告 §10.1 已經指出）。

**順帶一提**：剔除 UPRO 最佳筆反而讓組合 Calmar **上升**（+0.07 / +0.11）——
因為 UPRO 那筆 2020-04-30 → 2022-02-23 的大贏之後緊接著就是 2022 的 −37.5% 回撤，
它把權益墊高、也把後面的回撤基數墊高。**UPRO 腿對組合的貢獻是負的（Calmar 口徑）。**

### 8.1 視窗內

| | 值 | 距目標 |

| Calmar | **1.51** | ❌ **差 2.49**（要 Calmar 4，MDD 需縮到 **−7.7%**） |
| 最長水下 | 458 天 | — |
| 最差月 | −15.5% | — |

若允許單腿：TX新+step 100% 的 Calmar 2.01 是全表最高，但那不是分散，
而且它的 Calmar 有 44% 綁在兩筆交易上。）

### 8.2 折算回全期口徑（誠實版）

TX 三條腿在此視窗的 Calmar 膨脹倍數一致為 **×2.6~2.8**、CAGR 膨脹 **×1.5~1.8**。
假設美股腿同量級（**未經驗證，因為 FinLab 沒有 2016 前的美股資料**）：

> **TX 50/25/25 的全期口徑估計：CAGR 約 17.4%、Calmar 約 0.56。**
> 這與 TX 新腿單獨的全期數字（CAGR 20.8%、Calmar 0.63）在同一個檔次，
> 甚至略低。

### 8.3 判定

**跨市場分散沒有把 Calmar 推向 4，也沒有把它推離 0.6 這個量級。**
第一輪已經證明 Calmar 4 在單一市場不可達（神諭上界 2.26）；
本輪證明**加兩條相關度 0.15 的美股腿也不能達成** ——
因為那兩條腿在自己最有利的視窗裡 Calmar 只有 0.55 / 0.73，
分散降低的是波動，不是回撤與報酬的比值。

要把 Calmar 推到 4，需要的是**回撤結構本身不同的資產**
（例如真正的空頭避險、或報酬來源與股票 beta 無關的策略），
不是同一類「槓桿做多股票指數的回檔修復」策略再多來兩條。

## 10. 已知限制

1. **視窗只有 10.6 年且幾乎全是多頭。** TX 腿的 Calmar 在此視窗膨脹 ×2.7；
   美股腿無法折算。所有組合數字都應該按這個係數打折看。
2. **匯率完全沒有模型化。** UPRO / TQQQ 是美元計價；以台幣為本位會多一層波動，
   而且台股跌時台幣常同時弱，會**降低**實際分散效果。`allocation.md` §三.2 已指出。
3. **期貨整數口數的顆粒度沒有模型化。** SIG 再平衡假設資金可連續分割；
   實務上台指期最小單位是一口小台（`allocation.md` §三.1：目標槓桿下約需 82 萬）。
   本報告的 SIG 是「訊號時點」的模型，不是「口數」的模型。
4. **留一法的替代假設。** 剔除 TX 交易時用純核心 0.5x 報酬替代、剔除美股交易時用
   現金替代。前者比後者寬鬆（核心在多頭時有正報酬），所以 TX 的集中度
   可能還被**低估**了。
5. **權重固定，所以錨定 walk-forward 不適用**（教練已指出）。留一法檢驗的是
   報酬集中度，不是「當時選得到嗎」—— 兩者不能互相替代。
6. 美股腿沿用 `run_backtest` 的 ETF 版引擎（固定水位、非期貨注碼層），
   與 TX 腿的架構不同，兩者的「腿」不是同一種東西。這個不對稱本身
   就是 §9.3.1 建議先修美股腿的理由。
