# 最終套件：混合注碼 ＋ 核心 0.5x ＋ step-down

每日 Discord 訊息（`scripts/discord_daily.py`、單檔版 `dist/tx_daily_signal.py`）
自 2026-09 起採用的注碼規則。訊號層（進出場、停損線、失效線、移動停利）
**完全不變**，改的只有「買多少」與「賺多了要不要減」。

證據與驗證見 `docs/strategy.md` §18–§22 與 `docs/lab_mdd/`。

---

## 一句話

> 深回檔（均線下）的訊號固定押 3 倍；反環境（均線上）的訊號只給一半預算；
> 3 倍部位賺到 +150% 就減到 1 倍鎖住浮盈；空手時抱 0.5 倍核心。

## 規則總表

| 層 | 規則 | 參數 | 來源 |
|---|---|---|---|
| 訊號 | 自高點回檔 ≥10%，谷底起 ≤30 日內收盤補回 ≥60% → 進場 | `tuned` | §11 |
| 出場 | 收盤 < 停損線（補回一半 ×0.995）或 < 谷底 → 全出；創高後自最高收盤回檔 8% → 全出；120 日未創高 → 全出 | 不變 | §11 |
| 成交 | 指數 13:30 收盤判定，台指期 13:45 收盤成交（當日） | 不變 | futures.py |
| **注碼 A** | 進場日收盤 **< MA200** → 固定 **3x** | `BELOW_LEV=3` | §18/§20 |
| **注碼 B** | 進場日收盤 **≥ MA200**（或均線資料不足）→ **4% ÷ 停損距離**，上限 **2.5x** | `ABOVE_RISK_SCALE=0.5` | §20 |
| **step-down** | 部位權益達 **+150%**（期貨自進場 +50%）當日收盤 → 減碼到 **1x**，之後不加回；每筆一次、出場日不觸發 | `STEP_GAIN=1.5, STEP_LEV=1` | §22 |
| 核心 | 策略空手 → 持有 **0.5x**（每日再平衡）；一有訊號先平核心 | `CORE_LEVERAGE=0.5` | coverage.md／§19 |
| 核心濾網 | 站上 **MA200×1.02** 才開、跌破 **MA200×0.98** 才關，帶內不動作 | `CORE_BAND=0.02` | coverage.md §5 |

停損距離 = (訊號日收盤 − 停損線) ÷ 訊號日收盤。舊版是 8% ÷ 停損距離、上限 5x、不分均線、不減碼。

## 決策樹（每天 13:30 收盤後）

```
① 我有策略部位嗎？
│
├─ 沒有 ─┬─ 偵測器在 drawdown（追蹤回檔中）？
│        │   ├─ 收盤 ≥ 觸發價（T + 60%×(P−T)）→ 🟢 13:45 前買進
│        │   │     口數 = 權益 ÷ 每口需要，無條件捨去
│        │   │     每口需要 = ┬ 收盤 < MA200 交叉價：收盤 × 50 ÷ 3          （注碼 A，3x）
│        │   │                └ 收盤 ≥ MA200 交叉價：(收盤 − 停損線) × 1,250 （注碼 B，≤2.5x）
│        │   │     同時平掉核心（若持有）
│        │   ├─ 收盤 < 谷底 T → 破底，谷底與計時重來（不動作）
│        │   └─ 其餘 → 不動作；30 日視窗用盡則這段作廢、錨點改釘谷底後的波段高
│        └─ 不在追蹤 → 收盤 < P × 0.90 才開始追蹤（那天不進場）
│
│        （以上任何「不進場」的日子）核心：站上 MA200×1.02 開、跌破 MA200×0.98 關，帶內維持原狀
│
└─ 有 ──┬─ 收盤 < 谷底 T ────────────────→ 🔴 全數平倉（劇本失效）
         ├─ 收盤 < 停損線 ───────────────→ 🔴 全數平倉（警戒清倉）
         ├─ 已創過前高 P？
         │    ├─ 是：收盤 < 波段最高收盤 × 0.92 → 🔴 全數平倉（移動停利）
         │    └─ 否：收盤 > P → 記錄創高，啟動移動停利（不賣）
         ├─ 訊號後 120 日未創高 ──────────→ 🔴 全數平倉（劇本過期）
         ├─ 尚未減碼 且 期貨收盤 ≥ 進場價 × (1 + 1.5 ÷ 進場槓桿)
         │       （3x 部位即 ×1.50）───→ 🔻 減碼到 1x：口數 = 權益 ÷ (收盤 × 50)
         └─ 其餘 → 🟡 續抱，不動作
```

判斷優先序與程式一致（`engine.py` 第 244 行起、`futures.py` `vehicle_series`）：
失效線 → 停損線 → 移動停利 → 過期 → 減碼。減碼只在「今天不出場」時才檢查。

## 每日訊息哪一行對應哪條規則

| 訊息內容 | 規則 |
|---|---|
| `🟢 收盤 ≥ X → 買進，每 N 元 1 口小台（固定 3x／槓桿約 L）` | 注碼 A／B，依觸發價與 MA200 交叉價的相對位置 |
| `_觸發價在 MA200 交叉價 Y 之下 → 固定 3x；若收盤反而 ≥ Y，改半預算_` | 明天收盤可能落在交叉價兩側時的切換 |
| `② 收盤後怎麼算口數`：`收盤 < Y：收盤×50÷3` / `收盤 ≥ Y：(收盤−停損)×1250` ＋速查表 | 注碼 A／B 的口數公式 |
| `🔻 期貨收盤 ≥ 你的進場價 × 1.50（指數參考 ≈ Z）→ 減碼到 1x` | step-down 觸發（持有中） |
| `🔻 今天已觸發減碼：應已減碼至 1x` | step-down 當天（收盤後送達，屬確認） |
| `槓桿 3.00x → 已減碼 1x（日期）` | 減碼後的部位現況 |
| `⑥ 核心部位`：`策略空手，核心 0.5x 持有中／空手`、緩衝帶兩條門檻、`明日開啟／關閉門檻` | 核心規則 |
| 頁尾 `注碼 均線下 3x／均線上 4%÷停損距離≤2.5x　減碼 +150%→1x` | 目前生效的注碼設定 |

減碼觸發以**期貨價**判定（部位權益是真的），訊息附「指數參考」只是方便比對，
兩者差一個基差。非 3x 的部位（注碼 B）減碼門檻遠在 +150% 權益之外，
訊息仍會列出但實務上幾乎不會碰到。

## 口數公式（小台每點 50 元）

| 情境 | 每口需要的權益 | 等價槓桿 |
|---|---|---|
| 注碼 A（均線下） | 收盤 × 50 ÷ 3 | 3x |
| 注碼 B（均線上） | (收盤 − 停損線) × 1,250；若低於 停損線 × 2.5 ÷ 2.46 改為 收盤 × 50 ÷ 2.5 | 4% ÷ 停損距離，≤2.5x |
| 減碼後 | 收盤 × 50 ÷ 1 | 1x |
| 核心 | 收盤 × 50 ÷ 0.5 | 0.5x |

口數 = 權益 ÷ 每口需要，**無條件捨去**。資金不足一口就不做（不要用大台湊）。

## 預先登記的停用準則（從採用日起，每筆新訊號都是前瞻樣本）

1. 均線下（3x）的訊號出現期貨報酬 **< −5%**（該組歷史最差 −2.5%）→ 3x 前提被打破，改回風險式。
2. 停損執行落差連續兩筆 **> 2.5 倍** → 縮小槓桿上限。
3. **連虧 4 筆**（歷史最多 2）或回撤 **超過 −45%** → 停用並全面重檢。
4. 水下超過 **9 年** → 承認機制可能已死。
